# 模块六：Freeze 节点处理规则

`Freeze` 节点是用于在代码生成中复用现有设计元素的关键机制。它通过一个特殊的 web component `<freeze>` 标签来实现。在处理 `Freeze` 节点时，你必须严格遵守以下规则。

## 1. 属性说明

- **`data-key`**:
  - **作用**: 引用一个已存在的图层ID。
  - **规则**: 该属性与 `data-copy-key` 互斥，两者不能同时存在。当使用 `data-key` 时，表示直接复用设计稿中对应的图层。

- **`data-copy-key`**:
  - **作用**: 复制一个已存在的 `<freeze>` 节点。值的来源是另一个 `freeze` 节点的 `data-key`。
  - **规则**: 该属性与 `data-key` 互斥。当出现该属性时，意味着你需要从一个 `data-key` 属性值与 `data-copy-key` 相同的 `<freeze>` 节点复制一个新的实例。

- **`data-name`**:
  - **作用**: 提供对该 `freeze` 节点用途的描述，例如 "checkbox" 或 "avatar"。
  - **规则**: 这个属性是必须的。

- **`className`**:
  - **作用**: 用于布局占位。
  - **规则**: 这是一个固定值，**绝对不能修改**。在进行布局计算时，应将此节点视为一个具有固定尺寸的占位符。

## 2. 操作指令

### 节点保留与删除
- **保留**: 如果节点的功能是新 UI 所需要的，就保留它。
- **删除**: 如果节点的功能在新 UI 中不再需要，**必须将其从 HTML 结构中彻底删除**。不要保留不用的 `<freeze>` 节点。

### 节点复用
- **直接复用**: 对于带有 `data-key` 的节点，表示直接引用原始图层。如果新 UI 需要这个元素，就直接保留这个标签。
  ```html
  <!-- 直接使用 ID 为 "1:1" 的图层，其功能是 "checkbox" -->
  <freeze data-key="1:1" data-name="checkbox"></freeze>
  ```
- **复制复用**: 对于带有 `data-copy-key` 的节点，表示需要复制另一个 `<freeze>` 实例。
  ```html
  <!-- 复制一个 data-key="1:1" 的 freeze 节点 -->
  <freeze data-copy-key="1:1" data-name="checkbox"></freeze>
  ```

## 3. 核心原则
- **智能推断**: 你最重要的任务是**准确推断**每个 `freeze` 组件的**功能和作用**。
- **上下文判断**: 结合 `data-name` 属性和周围的 HTML 结构，来决定一个 `freeze` 节点是应该被保留、复制还是删除。错误的决策将导致 UI 生成不正确。
