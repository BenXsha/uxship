Usage 用法

Do / Don't

✓ Do

主操作使用 Primary，一屏只保留一个；次操作使用 Secondary / Outline。

✗ Don't

不要并排堆叠多个 Primary，也不要只用颜色区分状态（需配合文案/图标）。

✓ Do

Badge 语义色与含义一致（Success / Warning / Danger / Info）。

✗ Don't

不要把 Badge 当按钮用；可点击的用 Button / Tag。
